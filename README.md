# Daun Emas — Nasi Lemak Warisan

Laman web nasi lemak moden & mewah berkonsepkan tradisional daun pisang.

Buka `index.html` terus dalam pelayar — tiada proses build diperlukan.

- `index.html` — struktur laman (Hero, Kisah, Menu, Pengalaman, Ulasan, Tempahan, Lokasi)
- `styles.css` — tema hijau daun pisang, emas & krim santan
- `script.js` — navigasi, tab menu, slider ulasan, borang tempahan ke WhatsApp

Tukar nombor WhatsApp dalam `script.js` (`WHATSAPP_NUMBER`) serta alamat/telefon dalam `index.html`.
